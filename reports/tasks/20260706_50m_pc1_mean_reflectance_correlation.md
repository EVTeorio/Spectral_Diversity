# Task Report: 50 m PC1 Mean Reflectance Correlation

Date: 2026-07-06

## Objective

Compare mean spectral reflectance to PC1 using 250 sampled sunlit pixels from each current 50 m quadrat.

## Key Result

- Pixel-level Pearson r = 0.8916; R2 = 0.7949 using 20,000 sampled pixels.
- Quadrat-mean Pearson r = 0.9243; R2 = 0.8543 using 80 quadrat means.
