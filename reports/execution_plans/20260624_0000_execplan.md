- Validation Plan:
  - Confirm output row counts match expected scale grids where practical.
  - Confirm joins preserve `quad_id` and `scale`.
  - Confirm center coordinate columns are populated.

  - Confirm no duplicate `quad_id` values within each scale output.
- Risks:

  - Shapefile field-name truncation may require reading companion CSVs for full spectral/diversity/environment column names while using shapefiles only for geometry.
  - Centroid coordinates depend on source CRS; outputs will report the CRS used.
- Potential side effects:
  - Root-level CSV additions increase visible top-level files.
  - Documentation inventories will change to reflect the new combined outputs.
